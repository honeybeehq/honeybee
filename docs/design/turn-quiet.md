# Quiet turn completion

`bee.turn_quiet.v1` adds `lastTurnTrigger.endedQuiet?: boolean` to BeeRow snapshots and to the existing `runtime.updated` delta's `turnTrigger` payload. True means captured final assistant text contains only quiet tokens and blanks; false means captured text does not. An absent field means unknown, including historical rows, open turns, failed or interrupted turns, and completions without final text evidence. Each new turn starts without the field.

The classifier in `v2/core/src/quiet.ts` mirrors Apiary's `packages/core/src/quiet.ts` with SHA-256 `e8b28797cdd11c8bc132ec51ebcdbee6e419c657a8c1f73a7f51e9d01403f873`. Only `<quiet/>` tokens surrounded by blanks mark the reply quiet. Visible content followed by a trailing token is spoken: the token is stripped, `endedQuiet=false`, and a human-participating turn in legacy human-output mode advances `lastHumanOutputAt`. Explicit human-output mode advances that cursor only through `bee.tell`; see [explicit human output](./explicit-human-output-contract.md). This applies to every turn kind. The suffix scan skips whitespace, Unicode Default_Ignorable_Code_Point and U+2800, including astral code points. A token followed by visible text does not mark the reply quiet.

Quiet completions advance `lastOutputAt` but preserve `lastHumanOutputAt`. The latter now counts human-participating output except known quiet completions; unknown classifications preserve previous behavior. `output.recorded` continues publishing this cursor. Runtime, trigger and output facts commit atomically. The trigger is already stored as JSON, so this requires no schema or store version change. Audit replay and mirrors preserve the additive nested field.

Drivers capture final assistant text using the existing structured transcript projectors. Tool output cannot supply this fact. HSR excludes native sidechain rows and fences capture to the provider session and rebuilds it from the committed generation journal prefix when adopting a runner. The tmux driver classifies only terminal transcript evidence or final assistant text supplied by a native Stop/notify payload. Intermediate transcript text followed by a hook or quiescence cannot prove the final reply. Without terminal evidence or native final text, the classification stays unknown; completion and new-turn boundaries discard captured text. Projector failures leave classification unknown and cannot interrupt lifecycle observation. Tmux adoption skips pre-adoption transcript bytes, so a final message only present there remains unknown unless the completion hook supplies it.
