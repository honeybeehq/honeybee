# Honeybee brand icon

Honeybee uses **Strata U2**: stacked glowing hex plates in a dark slab. Apiary uses Hearth H4. Tormod chose this pairing; the design lead (Chris) made the art.

| File | Use |
| --- | --- |
| `strata-u2-1024.png` | Master artwork, 1024 × 1024 |
| `strata-u2.iconset/` | Every macOS icon size (16–512 pt, @1x and @2x) |
| `strata-u2.icns` | macOS app icon built from the iconset |
| `strata-hearth-pair.jpg` | Strata (Honeybee, right) next to Hearth (Apiary, left) |

Honeybee is a CLI and daemon with no app bundle, menu-bar item or docs site, so the README is the only place that shows the icon today. New surfaces should use these files and not redraw the mark.
