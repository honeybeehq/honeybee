# Honeybee release compatibility

Honeybee and Apiary use release evidence to determine which installed software
can work together. These terms describe that shared compatibility context.

## Language

**Standalone workstation service**:
An Apiary background service installed independently of the desktop app. The
desktop can attach to it, and the service can operate while the desktop is closed.

**Installed combination**:
The actual software releases participating in an interaction between devices,
including the service making the request and the service receiving it.

**Compatibility matrix**:
The evidence-backed assessment of software combinations as compatible,
incompatible, or unverified. Compatibility and an explicit support promise are
separate facts.

**Supported range**:
The releases supported for a particular software combination and device target,
with compatibility established by evidence. A range excludes incompatible releases
and does not imply support for releases whose compatibility is unverified.
