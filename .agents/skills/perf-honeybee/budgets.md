# Budgets

No operator latency budget has been ruled for remote Cell spawning.
Do not invent a seconds target from fixture verification captures.

The recipe asserts correctness: pinned independent checkout, unchanged origin,
real stub boot and first mail delivery, zero daemon tick/delivery violations, and
owned runner cleanup. Its 60-second readiness timeout and 10-second delivery/stop
timeouts are fixture failure bounds, not performance targets.

Only the operator rules latency budgets. Agents may propose budgets before an
optimization, retain baselines, and report same-series regressions.
