## Bounds and audit

Per Bee across generations, fixed 60000ms windows permit send60, question.ask12, seal.create12. They may burst at a window boundary and reset on daemon restart. UTF8 maxima: body65536B, text8192B, title512B, id128B, idempotencyKey256B; options32 with256B each; refs32 with1024B each. Input frames and transcript pages are capped at1048576B. Refusals use typed errors and bounded/coalesced rpc.local_refused rows with Bee, generation, verb and reason; request text and secrets are excluded. Scoped idempotency is per Bee+verb and survives revive.

## Scope and lifecycle

- Project membership is not authoritative in hived. Parent-only direct sends were approved for this slice. Apiary Project/orchestrator/cross-node messaging and proof_submit keep their authenticated Apiary transport; hived does not proxy them. ask is question.ask, and seal.create records only own seal metadata.
- Every child spawn is denied, including fresh Cells. All credential, lease, account admission, terminal/stdin, Cell exec, lifecycle, admin, update/install/deploy and thread fork/handoff routes are denied.
- bee.transcript is the only gateway transcript method. It reads bounded pages from the caller's daemon-owned log using NOFOLLOW,NONBLOCK,regular-file,canonical-root and descriptor/path inode checks. Other sessions and main/relay sockets are denied. Truncation is typed. Cell thread operations are already rejected by the local Codex HSR gate before indexed history lookup; independent history hardening is included above the hotfix base; canonical mapping is docs/security/t11/canonical.tsv.
- Sockets are per daemon instance and current Bee generation. Long homes use a private randomly allocated /tmp directory. The launcher treats the returned source path as opaque and restores only that inode at /run/honeybee/gateway.sock. No existing socket is probed/replaced. Stopped listeners fail authentication immediately and are reaped within30s; a new generation closes old listeners.
- Daemon restart intentionally fails closed: surviving runtimes retain a dead old socket mount until relaunch/remount. Core runtime survival is separate from uninterrupted RPC. No real-socket or stale-store fallback is permitted.
- HIVE_CELL_GATEWAY_SOCKET overrides CLI socket flags and endpoint records. In-Cell transcript/tail and send use this route. CLI code is mounted readonly at /run/honeybee/hive.mjs and invoked by the readonly shim.
- Privileged cell.exec carries the exact current source-generation gateway only; executor processes do not inherit runtime ancestry and cannot authenticate to it. Missing runtimes do not fabricate generation0, and stale provisioning fails before any newer listener is closed.
- The T11 full-root allowlist is a release dependency. The former readonly-root layout exposed an existing custom /mnt fixture daemon socket; the same fixture is ENOENT after the full-root change. Both variants assert socket/store/log host existence first. The runner uses a hash-equal code-only copy of the same Node binary with trusted ownership in a readonly overlay; no guard bypass or credential copy.
